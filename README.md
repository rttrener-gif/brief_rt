# Министерство ИИ — Интерактивная презентация

Интерактивная HTML-страница с калькулятором рентабельности, ролями и компетенциями.

## Структура проекта

```
ministry-ai-site/
  public/
    index.html        # Основной файл (самодостаточный, всё в одном)
  google-apps-script/
    Code.gs            # Скрипт для Google Apps Script (запись в таблицу)
  vercel.json          # Конфиг для деплоя на Vercel
  package.json
  README.md
```

## Как это работает

1. **HTML на Vercel** — красивая интерактивная страница с калькулятором, доступная по ссылке
2. **Google Таблица** — хранит контент (роли, компетенции, тексты) как единый источник истины
3. При загрузке страница подтягивает данные из таблицы; при сохранении — пишет обратно

## Настройка за 4 шага

### Шаг 1: Создать Google-таблицу

1. Создайте новую Google-таблицу: https://sheets.new
2. Назовите первый лист `data`
3. В ячейку **A1** ничего пока не пишите (туда будет записываться JSON автоматически)
4. **Файл → Поделиться → Опубликовать в интернете** → выберите лист `data`, формат CSV → нажмите «Опубликовать»
5. Скопируйте **ID таблицы** из URL (между `/d/` и `/edit`):
   ```
   https://docs.google.com/spreadsheets/d/ЭТОТ_ID_НУЖЕН/edit
   ```

### Шаг 2: Создать Google Apps Script (для записи)

1. В таблице: **Расширения → Apps Script**
2. Удалите содержимое `Code.gs` и вставьте код из файла `google-apps-script/Code.gs`
3. Нажмите **Развернуть → Новое развёртывание**
4. Тип: **Веб-приложение**
5. Выполнять от имени: **Меня**
6. Доступ: **Все** (или «Все в организации», если корпоративный Google)
7. Нажмите **Развернуть**, пройдите авторизацию
8. Скопируйте URL веб-приложения

### Шаг 3: Вписать ключи в index.html

Откройте `public/index.html` и найдите строки:

```javascript
const SHEET_ID = '';        // Вставьте ID таблицы
const APPS_SCRIPT_URL = ''; // Вставьте URL веб-приложения
```

### Шаг 4: Задеплоить на Vercel

**Вариант A — через CLI:**
```bash
npm i -g vercel
cd ministry-ai-site
vercel
```

**Вариант B — через GitHub:**
1. Создайте репо на GitHub и запушьте этот проект
2. Зайдите на https://vercel.com → Import Project → выберите репо
3. Vercel автоматически задеплоит

После деплоя вы получите ссылку вида `https://ministry-ai.vercel.app`

## Как коллеги будут работать

### Редактирование через HTML (для тех, кому удобно):
1. Открыть ссылку на сайт
2. Нажать кнопку «Редактировать» (внизу справа)
3. Внести правки прямо на странице
4. Нажать «Сохранить» — данные уходят в Google Sheets

### Редактирование через Google Sheets (для тех, кому привычнее):
1. Открыть таблицу (дать доступ на редактирование)
2. В ячейке A1 лежит JSON — его можно редактировать напрямую, но проще через HTML
3. Изменения подтянутся при следующей загрузке страницы

### Экспорт:
- Кнопка «Экспорт» скачивает полностью автономный HTML-файл со всеми текущими данными

## Без Google Sheets

Если не хочется настраивать Google Sheets — всё работает и без него:
- Данные сохраняются в localStorage браузера
- Кнопка «Экспорт» позволяет скачать файл и передать коллегам
- Единственный минус: нет общего состояния между пользователями
